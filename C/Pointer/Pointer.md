# C语言指针

## 1. 指针是什么

指针变量用于存储变量的地址。

例如：

```c
#include <stdio.h>

int main()
{
    int a = 10;
    int* p = &a;

    printf("a = %d\n", a);
    printf("a的地址 = %p\n", &a);
    printf("*p = %d\n", *p);

    return 0;
}
```


## 2.重点：

int a = 10;

int* p = &a;

创建一个int*类型的变量p，让它保存a的地址

## 3.彻底搞懂

a：变量本身 ->10

&a: &取地址运算符；得到a在内存中的地址 ->1000

```text
a
┌───────┐
│  10   │
└───────┘
  1000
```

p:指针变量，保存a的地址(p → &a) ->1000

*p：*解引用；去p保存的那个地址，找到里面的变量 ->10

  
指针类型

NULL
