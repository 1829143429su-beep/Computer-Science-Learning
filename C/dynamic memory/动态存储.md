#### #include <stdlib.h>

告诉编译器：

malloc() 返回的是一个指针，并且它的函数声明是什么。

#### 1.malloc()
int* p = malloc(5 * sizeof(int));
```c
向系统申请能够存放 5 个 int 的空间。
申请成功之后，会返回：这块内存空间的首地址
       malloc申请的空间
   ┌────┬────┬────┬────┬────┐
   │ 10 │ 20 │    │    │    │
   └────┴────┴────┴────┴────┘
     ↑
     p

*p = 10;//内存首个元素
p++ 和 *(p + i) 仍旧可以使用
```

以前：
```text
int arr[5];//数组空间已经存在  
int* p = arr;    
使用
```

现在：
```text
malloc() -> 申请空间 -> 返回地址 -> int* p -> 使用
```

```c
#include <stdio.h>
#include <stdlib.h>

int main()
{
    int* p = malloc(5 * sizeof(int));

    p[0] = 10;
    p[1] = 20;
    p[2] = 30;
    p[3] = 40;
    p[4] = 50;

    for (int i = 0; i < 5; i++) {
        printf("%d ", p[i]);//结果10 20 30 40 50
    }

    free(p);
    return 0;
}
```

malloc必须检查是否成功

如果成功，返回有效地址；

如果申请失败：malloc() 会返回NULL（即p==NULL）。

标准写法：
```c
int* p = malloc(5 * sizeof(int));

if (p == NULL) {
    printf("内存申请失败\n");
    return 1;
}
然后才使用：
p[0] = 10;
```


#### 2.free()
malloc -> 申请-> 使用 -> 释放

```text
int* p = malloc(5 * sizeof(int));
free(p);//此时堆空间已经释放

但是 p这个指针变量本身还存在,它里面可能还保存着原来的地址！
这就产生了一个非常重要的问题：p 现在指向的空间已经不存在了！
这种指针叫：悬空指针（跑空了）

所以推荐：
int* p = malloc(...);
if (p != NULL)
{
    // 才使用
}
free(p);//释放空间
p=NULL;//不再让 p 指向已经释放的空间
```

#### 3.calloc()
它也是申请5个int,

但和 malloc() 有一个重要区别：calloc() 申请的空间会被初始化为 0!!!

int* p = calloc(5, sizeof(int));//格式


#### 4.realloc()
调整已经申请的动态内存大小。

int* p = malloc(5 * sizeof(int));

现在只有 5 个 int,如果想变成 10 个：

p = realloc(p, 10 * sizeof(int));

这里有一个非常重要的安全写法，
```c
int* temp = realloc(p, 10 * sizeof(int));
if (temp != NULL)
{
    p = temp;
}
```
```text
arr
 ↓
原来的内存

temp = realloc(arr,...)
 ↓
尝试扩容

成功 → temp获得新空间 → arr = temp
失败 → temp == NULL → arr仍然保留原来的空间
```

#### 6：动态数组排序

把之前的：指针 + 冒泡排序

改成：malloc + 指针 + 冒泡排序

```text
while (i < 5) {
    printf("%d ", *p);
    i++;
    p++;//已经把 p 移走了
}
循环结束以后：p -> arr + 5
所以你后面free(p) 是错误的！
因为free()必须传入 malloc 返回的原始地址
不能传：
p + 1
p + 2
p + 3

不要让 p 在遍历过程中移动。
可以重新定义一个指针：
int* cur = p;
while (i < 5) {
    printf("%d ", *cur);
    cur++;
    i++;
}
free(p);
p = NULL;
```
