malloc()

### 彻底搞懂：
```c
栈
│
│
└── 局部变量

│

```

### 重点理解：
为什么需要 malloc()？

因为程序运行之前，我们可能根本不知道需要多少内存

### 栈和堆
程序运行时的内存
```c
┌─────────────────────┐
│        栈 Stack     │
│                     │
│ int a = 10;         │
│ int arr[5];         │
│ 局部变量             │
│                     │
├─────────────────────┤
│                     │
│        堆 Heap      │
│                     │
│ malloc申请的空间     │
│                     │
└─────────────────────┘
```

#### 1.malloc()
int* p = malloc(5 * sizeof(int));
```c
向系统申请能够存放 5 个 int 的空间。
申请成功之后，会返回：这块内存空间的首地址
       malloc申请的空间
   ┌────┬────┬────┬────┬────┐
   │ 10 │ 20 │    │    │    │
   └────┴────┴────┴────┴────┘
     ↑
     p

*p = 10;//
p++ 和 *(p + i) 仍旧可以使用
```

以前：
```text
int arr[5];//数组空间已经存在  
int* p = arr;    
使用
```

现在：
```text
malloc() -> 申请空间 -> 返回地址 -> int* p -> 使用
```

```c
#include <stdio.h>
#include <stdlib.h>

int main()
{
    int* p = malloc(5 * sizeof(int));

    p[0] = 10;
    p[1] = 20;
    p[2] = 30;
    p[3] = 40;
    p[4] = 50;

    for (int i = 0; i < 5; i++) {
        printf("%d ", p[i]);//结果10 20 30 40 50
    }

    free(p);
    return 0;
}
```

如果申请失败：malloc() 会返回NULL

标准写法：
```c
int* p = malloc(5 * sizeof(int));

if (p == NULL) {
    printf("内存申请失败\n");
    return 1;
}

然后才使用：
p[0] = 10;
```




#### 2.free()
malloc -> 申请-> 使用 -> 释放
```c
int* p = malloc(...);
/* 使用 p */
free(p);
```

```text
int* p = malloc(5 * sizeof(int));
free(p);//此时堆空间已经释放

但是 p这个指针变量本身还存在,它里面可能还保存着原来的地址。
这就产生了一个非常重要的问题：p 现在指向的空间已经不存在了。
这种指针叫：悬空指针

所以推荐：
free(p);//释放空间
p = NULL;//不再让 p 指向已经释放的空间
```
