## 栈
#### 定义：
```text
栈是一种特殊的线性数据结构，它遵循：
后进先出（LIFO，Last In, First Out）
想象一下，你把几本书依次叠起来，最后放上去的书，通常最先拿走。
```
#### 存储分类：
栈可以用不同方式实现：
```
- 顺序栈：使用数组存储元素。
- 链栈：使用链表存储元素。
```

#### 栈的两个基本操作：
```text
push	入栈，把元素放进去	放入 40
pop	  出栈，取出栈顶元素	取出 30
```

2.教材

```text
#define MAXSIZE 100
typedef struct {
```


### 基本操作
#### 1.初始化
```c
void init_stack(SqStack* s)
{
    s->top = -1;
    printf("栈初始化成功！\n");
}
```
为什么参数是 SqStack* s？

因为我们要修改调用者的栈的 top。传入栈的地址后，通过 s->top 修改原来的结构体。

使用方式：
```c
SqStack s;
init_stack(&s);  //这里的 &s 就是把栈 s 的地址传给函数。
```

#### 2.入栈
先top++;再添加数据
```c
bool Push(SqStack*s,int data) {
	if (s->top == MAXSIZE-1) {
		printf("栈已满,入栈失败\n");
		return false;
	}
	s->top++;
	s->data[s->top] = data;

	printf("入栈成功：%d\n", data);
	return true;
}
```

#### 3.出栈
先保存数据，再top--
```c
bool Pop(SqStack* s,int *data) {
	if (s->top == -1) {
		printf("栈空，出栈失败\n");
		return false;
	}
	*data = s->data[s->top];
	s->top--;

	return true;
}
```
调用时：
```c
int e;
if (Pop(&s, &e)) {
    printf("出栈元素：%d\n", e);
}
```

#### 4.获取栈顶元素
```c
bool GetTop(SqStack* s, SElemType* e)
{
	if (s->top == -1) {
		printf("栈空\n");
		return false;
	}
	*e = s->data[s->top];
	return true;
}
```
```c
调用：
SElemType e;

if (GetTop(&s, &e)) {
    printf("栈顶元素是：%d\n", e);
}
```

#### 5.获取当前栈中有多少个元素
元素个数 = top + 1

#### 6.判断栈空
```c
bool StackEmpty(SqStack s) {
    return s.top == -1;
}
```

#### 7.清空栈
可以直接赋值，不需要循环
```
void ClearStack(SqStack* s) {
    s->top = -1;
    printf("栈已清空！\n");
}
//清空栈只需要修改有效元素的边界，不需要逐个删除数组中的元素。
//原来的 10、20、30 可能还留在数组内存中，但已经不属于栈的有效内容。
//另外，void 函数执行到末尾会自动返回，所以 return; 也可以省略。
```

#### 8.销毁栈
```text
清空栈和销毁栈在当前实现中没有明显的内存操作区别：
- 清空栈：把 top 设为 -1，栈还可以继续使用。
- 销毁栈：当前结构体不需要 free，因为没有单独申请堆内存；如果后续不再使用这个栈，让结构体变量生命周期结束即可。
```

### 栈的应用
#### 括号匹配检查
不同类型的括号
```text
遇到左括号 (、[、{：入栈。

遇到右括号 )、]、}：检查栈顶的左括号。
- 栈为空：匹配失败。
- 栈顶括号与当前右括号匹配：弹出栈顶。
- 不匹配：匹配失败。

所有字符处理完后：
- 栈为空：匹配成功。
- 栈不为空：匹配失败，因为还有左括号没有匹配。
```
### 栈应用于三种表达式
```text
它们的区别在于：运算符相对于操作数的位置不同。
中缀    A + B     运算符在中间
前缀    + A B     运算符在前面
后缀     A B +    运算符在后面
```
##### 中缀表达式
```text
运算符优先级，例如乘除优先于加减。
括号，例如 (A+B)*C。
运算符结合性，例如 A-B-C 通常按从左到右计算。
```
用栈实现：！！！！！！！！
```text
初始化两个栈，操作数栈和运算符栈
若扫描到操作数，压入操作数栈；
若扫描到运算符或界限夫，则按照中缀转后缀 相同的逻辑压入运算符栈；
期间也会弹出运算符，每弹出一个运算符，就需要再弹出两个操作数的栈顶元素并执行相应元素，运算结果再压回操作数栈
```

##### 中缀表达式转换为后缀表达式！！！！！
一、手算：
```text
确定各个运算符的运算顺序；
选择下一运算符，按照[左操作数 右操作数 运算符]的方式组合成一个新的操作数；
如果还有运算符没被处理，继续第二步。
注：
左优先原则：只要左边的运算符能先计算，就有先计算左边的（可保证运算顺序唯一）
```
二、机算
```text
初始化一个栈，用于保存暂时还不能确定运算顺序的运算符。
从左向右扫描中缀表达式：
1. 遇到操作数：直接加入后缀表达式。
2. 遇到左括号 (：入栈。
3. 遇到右括号 )：不断弹出并输出运算符，直到遇到左括号；左括号弹出但不加入后缀表达式。
4. 遇到运算符：比较它与栈顶运算符的优先级。
   - 栈顶运算符优先级更高，或优先级相同且当前运算符按左结合处理：弹出并输出栈顶运算符。
   - 然后将当前运算符入栈。
5. 扫描结束：将栈中剩余运算符依次弹出并输出。
```
例子：
```text
中缀表达式： A+B-C*D/E+F
A 直接加入后缀（A）
+ 栈空，无高级或同级，入栈(+)
B 直接加入后缀（AB）
- 有同级运算符，弹出栈顶+（AB+），再压入-（-）
C 直接加入后缀（AB+C）
* 无高级或同级，入栈（-*）
D 直接加入后缀（AB+CD）
/ 有同级，弹出栈顶*（AB+CD*），压入/（-/）
E 直接加入后缀（AB+CD*E）
+ 有高级和同级，弹出栈顶/、-（AB+CD*E/-），压入+（+）
F 直接加入后缀（AB+CD*E/-F）
弹出+（AB+CD*E/-F+）

对应的后缀表达式：AB+CD*E/-F+
```

##### 后缀表达式的计算！！！！！！
一、手算
```text
从左往右扫描，每遇到一个运算符，就让运算符前最近的两个操作数执行对应运算，合为一个操作数；
注意操作数的左右顺序（会影响除法）
```
二、机算
用栈实现：
```text
从左往右扫描下一个元素，直到处理完所有元素；
若扫描到操作数则压入栈，并继续第一步；否则执行第三步；
若扫描到运算符，则弹出两个栈顶元素，执行相应运算，运算结果压回栈顶，继续第一步。
注意：先出栈的是右操作数！！！
```

##### 中缀表达式转前缀表达式
一、手算
```text
确定各个运算符的运算顺序；
选择下一运算符，按照[运算符 左操作数 右操作数]的方式组合成一个新的操作数；
如果还有运算符没被处理，继续第二步。
注：
右优先原则：只要左边的运算符能先计算，就有先计算右边的。
```
##### 后缀表达式的计算
用栈实现：
```text
从右往左扫描下一个元素，直到处理完所有元素；
若扫描到操作数则压入栈，并继续第一步；否则执行第三步；
若扫描到运算符，则弹出两个栈顶元素，执行相应运算，运算结果压回栈顶，继续第一步。
注意：先出栈的是左操作数！！！
```

#### 栈的应用——递归
函数调用栈：
```text
后调用的函数先返回，先调用的函数后返回，也就是后进先出（LIFO）。

函数调用时，需要一个栈存储：
调用返回地址；
实参；
局部变量。
```

递归必须有两个重要部分：
```text
1. 终止条件：确定什么时候不再继续递归。
2. 递归关系：每次调用都向终止条件推进。
```
递归可以把原始问题转换为规模较小的问题：

计算阶乘：
```c
int factorial(int n){
    if(n==0||n==1)
       return 1;
    else
       return n*factorial(n-1);
}
int main(){
   //...其他代码
   int x=factorial(10);
   printf("奥里给！”);
}

```
注意：每一层虽然执行的是同一个函数，但它们的参数值不同，各自的调用状态也独立保存。

递归调用栈的工作过程
```text
以 factorial(10) 为例：
1. 递归进入： 每进入一层递归，就建立相应的调用栈帧，并保存该层的运行信息。
2. 递归返回： 当递归达到终止条件后，开始逐层返回，撤销对应的栈帧。
3. 恢复执行： 每一层获得下一层的返回值，完成自身计算，再返回上一层。
```

 
## 链式栈
### 对比
```text
顺序栈用固定大小的数组保存元素，top 记录栈顶下标。
10 20 30 空位
栈顶是 30。

链式栈：使用链表节点来保存元素，不需要提前定义固定的数组容量。
栈顶
30 -> 20 -> 10 -> NULL
节点通过指针连接，栈顶指向第一个节点。
我们约定：链式栈的栈顶放在链表头部，这样入栈和出栈都很方便。
```

### 结构体定义
```c
typedef struct Node {
    int data;
    struct Node* next;
} Node;

typedef struct {
    Node* top;//一个指针，而不是顺序栈里那种下标
} LinkStack;

//空链栈的 top = NULL
```

### 基本操作
#### 1.初始化
让栈顶指针指向空
```c
void InitStack(LinkStack* s) {
    s->top = NULL;
    printf("链式栈初始化成功！\n");
}
```

#### 2.入栈
```c
//2.入栈
bool Push(LinkStack* s, int data) {
	// 1. 创建新节点
	Node* newNode = malloc(sizeof(Node));


	// 2. 判断内存申请是否成功
	if (newNode != NULL) {
		printf("内存申请成功\n");
	}
	else {
		return false;
	}

	// 3. 给新节点赋值
	newNode->data = data;

	// 4. 让新节点指向原来的栈顶
	newNode->next = s->top;

	// 5. 更新栈顶指针
	s->top = newNode;

	return true;
}
```

#### 3.出栈
```c
bool Pop(LinkStack* s,int*e) {
	// 1. 判断栈是否为空
	if (s->top == NULL) {
		printf("栈空\n");
		return false;
	}

   // 2. 保存原来的栈顶节点
	Node* temp = s->top;

   // 3. 将栈顶节点的数据传给 e
	*e = s->top->data;

   // 4. 更新栈顶指针
	s->top = temp->next;

   // 5. 释放原栈顶节点
	free(temp);

	printf("出栈成功，元素为：%d\n", *e);
	return true;
}
```

#### 4.获取栈顶元素
```c
bool GetTop(LinkStack* s, int* e) {
	// 判断栈是否为空
	if (s->top == NULL) {
		printf("栈空\n");
		return false;
	}
	*e = s->top->data;
	return true;
```

#### 7.清空
释放链式栈中的所有节点，并将栈恢复为空栈
```c
void ClearStack(LinkStack* s) {
	if (StackEmpty(s)) {
		return;
	}

	Node* cur = s->top;
	//遍历
	while (cur) {
		Node* temp = cur;
		cur=cur->next;
		free(temp);
	}
	s->top = NULL;
	printf("栈已为空\n");
}
```
