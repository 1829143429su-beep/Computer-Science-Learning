# 双链表

```text
NULL ← [10] ⇄ [20] ⇄ [30] → NULL

每个节点有两个指针：
struct Node* prev;
struct Node* next;

所以一个节点可以知道：前一个节点 ← 当前节点 → 后一个节点
```


### 
#### 节点结构
```c
typedef struct Node
{
    int data;
    struct Node* prev;
    struct Node* next;
} Node;
```
```text
        prev          next
         ↓             ↓
NULL ← [10] ⇄ [20] ⇄ [30] → NULL
```

#### 创建第一个双向链表节点
假设它存 10。
```c
Node* create_node(int data)
{
    Node* newNode = malloc(sizeof(Node));

    newNode->data = data;
    newNode->prev = NULL;
    newNode->next = NULL;

    return newNode;
}
调用：
Node* head = create_node(10);
这里是返回新节点的地址。
```

```c
void create_node(Node** pp) {
    *pp = malloc(sizeof(Node));
    (*pp)->data = 10;
    (*pp)->prev = NULL;
    (*pp)->next = NULL;
}

调用
Node* head = NULL;
create_node(&head);

//逻辑没有问题，主要只是 data = 10 写死了。
```

### 对比单链表
#### 1.插入：
单链表插入时，我们以前只需要修改两个连接：
```c
newNode->next = cur->next;
cur->next = newNode;
```
双向链表因为多了 prev，所以连接一个节点时通常需要同时维护前后两个方向。

双向链表插入则要维护 4 条关系：
```text
前一个.next → 新节点
新节点.prev → 前一个

新节点.next → 后一个
后一个.prev → 新节点
```
#### 在指定节点cur后面插入节点。
```c
void insert_after(Node* cur, int data)
```
#### 在指定节点cur前面插入节点。
```c
void insert_before(Node**pp,Node* cur, int data)
```

```text
如果 cur 是头节点，外部的 head 也要更新成 newNode。
void insert_before(Node** pp, Node* cur, int data)
{
    Node* newNode = create_node(data);
}
```

#### 3.双向链表的遍历：不仅能从头往后走，还能从尾往前走。

① 从头往后遍历
```c
void print_forward(Node* head)
{
    Node* cur = head;

    while (cur != NULL) {
        printf("%d ", cur->data);
        cur = cur->next;
    }
}
```
```text
这个和你之前单链表的遍历几乎一样：
cur
 ↓
10 → 20 → 30 → NULL
```

② 从尾往前遍历
```text
这里就是双向链表的重点;我们需要先找到最后一个节点。

                        tail
```
寻找尾节点：
```c
Node* get_tail(Node* head)
```
