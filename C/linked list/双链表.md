# 双链表

```text
NULL ← [10] ⇄ [20] ⇄ [30] → NULL

每个节点有两个指针：
struct Node* prev;
struct Node* next;

所以一个节点可以知道：前一个节点 ← 当前节点 → 后一个节点
```

### 对比单链表
#### 插入：
单链表插入时，我们以前只需要修改两个连接：
```c
newNode->next = cur->next;
cur->next = newNode;

双向链表因为多了 prev，所以连接一个节点时通常需要同时维护前后两个方向。
```

### 
#### 节点结构
```c
typedef struct Node
{
    int data;
    struct Node* prev;
    struct Node* next;
} Node;
```
```text
        prev          next
         ↓             ↓
NULL ← [10] ⇄ [20] ⇄ [30] → NULL
```

#### 创建第一个双向链表节点
假设它存 10。
```c
Node* create_node(int data)
{
    Node* newNode = malloc(sizeof(Node));

    newNode->data = data;
    newNode->prev = NULL;
    newNode->next = NULL;

    return newNode;
}
调用：
Node* head = create_node(10);
这里是返回新节点的地址。
```

```c
void create_node(Node** pp) {
    *pp = malloc(sizeof(Node));
    (*pp)->data = 10;
    (*pp)->prev = NULL;
    (*pp)->next = NULL;
}

调用
Node* head = NULL;
create_node(&head);

//逻辑没有问题，主要只是 data = 10 写死了。
```
