# 双链表

```text
NULL ← [10] ⇄ [20] ⇄ [30] → NULL

每个节点有两个指针：
struct Node* prev;
struct Node* next;

所以一个节点可以知道：前一个节点 ← 当前节点 → 后一个节点
```


### 
#### 节点结构
```c
typedef struct Node
{
    int data;
    struct Node* prev;
    struct Node* next;
} Node;
```
```text
        prev          next
         ↓             ↓
NULL ← [10] ⇄ [20] ⇄ [30] → NULL
```

#### 创建第一个双向链表节点
假设它存 10。
```c
Node* create_node(int data)
{
    Node* newNode = malloc(sizeof(Node));

    newNode->data = data;
    newNode->prev = NULL;
    newNode->next = NULL;

    return newNode;
}
调用：
Node* head = create_node(10);
这里是返回新节点的地址。
```

```c
void create_node(Node** pp) {
    *pp = malloc(sizeof(Node));
    (*pp)->data = 10;
    (*pp)->prev = NULL;
    (*pp)->next = NULL;
}

调用
Node* head = NULL;
create_node(&head);

//逻辑没有问题，主要只是 data = 10 写死了。
```

### 对比单链表
#### 1.插入：
单链表插入时，我们以前只需要修改两个连接：
```c
newNode->next = cur->next;
cur->next = newNode;
```
双向链表因为多了 prev，所以连接一个节点时通常需要同时维护前后两个方向。

双向链表插入则要维护 4 条关系：
```text
前一个.next → 新节点
新节点.prev → 前一个

新节点.next → 后一个
后一个.prev → 新节点
```
#### 在指定节点cur后面插入节点。
```c
void insert_after(Node* cur, int data)
```
#### 在指定节点cur前面插入节点。
```c
void insert_before(Node**pp,Node* cur, int data)
```

```text
如果 cur 是头节点，外部的 head 也要更新成 newNode。
void insert_before(Node** pp, Node* cur, int data)
{
    Node* newNode = create_node(data);
}
```

#### 3.双向链表的遍历：不仅能从头往后走，还能从尾往前走。

① 从头往后遍历
```c
void print_forward(Node* head)
{
    Node* cur = head;

    while (cur != NULL) {
        printf("%d ", cur->data);
        cur = cur->next;
    }
}
```
```text
这个和你之前单链表的遍历几乎一样：
cur
 ↓
10 → 20 → 30 → NULL
```

## 第一部分：双向链表基本操作补全
### 一、基本操作
#### 1. 按值查找
编写 `find_node(head, data)`，返回第一个匹配节点；不存在返回 `NULL`。

#### 2. 修改节点
编写 `modify_node(head, oldData, newData)`，修改第一个匹配节点的值，返回是否修改成功。

#### 3. 统计长度
编写 `get_length(head)`，返回节点总数。

#### 4. 查找最大值与最小值
分别编写函数，返回最大值或最小值；空链表要有合理处理。

#### 5. 删除第一个匹配值
独立实现，不调用 `delete_node()`；处理头节点、中间节点、尾节点和不存在的值。

#### 6. 删除所有匹配值
独立实现，不调用任何删除函数；注意连续匹配节点以及释放内存。


### 二、插入与删除进阶
#### 7. 按位置删除
编写 `delete_pos(&head, pos)`，删除第 `pos` 个节点；检查空链表、非法位置、只有一个节点等情况。

#### 8. 按位置插入
完善你刚写的 `insert_pos(&head, pos, data)`，允许插入头部、中间、尾部以及空链表的第一个位置。

#### 9. 在有序链表中插入
假设链表按从小到大排列，插入新值后仍然有序；重复值放在已有相同值之前。

#### 10. 删除重复值
保留每个值第一次出现的节点，删除后续重复节点。例如 `1⇄2⇄1⇄3⇄2` 变为 `1⇄2⇄3`。
```text
你可以考虑这样拆分思路：
1. 用 cur 遍历链表，依次选中每个节点。
2. 用另一个指针，从 cur 的下一个节点开始检查。
3. 如果发现值与 cur->data 相同，就删除那个节点。
4. 如果不同，就继续向后检查。
```


### 三、链表综合操作
#### 11. 反转链表
独立实现，不调用其他反转函数；反转后 `head` 指向原来的尾节点，并确保 `prev`、`next` 正确。
```text
1.交换数据
你可以使用两个指针：
- left 从头节点开始。
- right 从尾节点开始。
- 交换两者的 data，然后 left 向后移动，right 向前移动。
- 当两个指针相遇（left==right）或交错(left>right)时结束。
```

一个关键问题：while (right > left)。
```text
为什么这个判断不对？
right 和 left 都是节点指针，比较它们的大小是在比较内存地址，而不是判断谁在链表前面。
```


```text
2.修改指针
直接调整每个节点的 prev 和 next，让链表的连接方向反过来。
这种方式不改变节点保存的数据，只改变节点之间的连接关系。

先保存下一节点，再修改当前节点，最后移动指针。
```


#### 12. 清空链表
释放所有节点，最后将调用者的 `head` 设为 `NULL`。

#### 13. 合并两个有序链表
将两个升序双向链表合并为一个升序链表；尽量复用已有节点，不重新创建数据节点。

#### 14. 判断是否有序
编写函数，判断链表是否从小到大排列。

#### 15. 查找倒数第 k 个节点
例如 `k=1` 返回尾节点；考虑 `k` 非法或大于链表长度的情况。
