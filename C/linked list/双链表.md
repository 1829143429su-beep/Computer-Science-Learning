# 双链表

```text
NULL ← [10] ⇄ [20] ⇄ [30] → NULL

每个节点有两个指针：
struct Node* prev;
struct Node* next;

所以一个节点可以知道：前一个节点 ← 当前节点 → 后一个节点
```

### 对比单链表
#### 插入：
单链表插入时，我们以前只需要修改两个连接：
```c
newNode->next = cur->next;
cur->next = newNode;

双向链表因为多了 prev，所以连接一个节点时通常需要同时维护前后两个方向。
```

### 
#### 节点结构
```c
typedef struct Node
{
    int data;
    struct Node* prev;
    struct Node* next;
} Node;
```
```text
        prev          next
         ↓             ↓
NULL ← [10] ⇄ [20] ⇄ [30] → NULL
```

#### 创建第一个双向链表节点
```c
Node* head = malloc(sizeof(Node));
