#### 3.插入结点
[10] → [20] → [30] → NULL

假设我们想在 10 和 20 中间插入一个 15：
```c
Node* p;      // 已经指向10
Node* newNode; // 需要申请空间，再指向15
插入节点：先接后面，再接前面。
newNode->next = p->next;  // 先接住后面的节点
p->next = newNode;       // 再让前面的节点接新节点
```

#### 4.删除指定位置的节点
核心语句：
```c
cur->next = cur->next->next;
```
```text
删除下标 pos
        ↓
cur 停在 pos - 1
        ↓
我们先把要删除的节点保存下来：
Node* temp = cur->next;
free(被删除的节点); //否则会造成内存泄漏。
        ↓
cur->next = cur->next->next
```

还有 两个边界情况需要处理
```text
① pos = 0 会出问题
pos = 0;
条件变成：i < -1，循环不会执行。
于是 cur 还是指向头节点

解决：
if (pos == 0)
{
   Node* temp = *pp;       // ① 保存旧头结点地址
   *pp = (*pp)->next;      // ② 让p指向下一个结点
    free(temp);            // ③ 释放旧头结点
    return;
}
//p 和 temp 是两个指针变量，但它们保存的是同一个地址。
//先用一个临时指针temp保存重要的地址，等确认操作完成后，再处理原来的指针

```
```text
② pos 超出范围时还可能出问题
```

#### 8.链表逆序！！！
```text
第一个指针：cur
Node* cur = p;
它负责：当前正在处理的节点。

第二个指针：prev
Node* prev = NULL;
它负责：当前节点的前一个节点。

这就是第三个指针：next
Node* next;
它负责：下一个节点


初始：
  prev       cur       
   ↓          ↓          
  NULL       [10]  →   [20]  →   [30]  → NULL
```

然后第一次执行：保存 20，然后反转 10 的箭头
```c
Node* cur = p; //cur指向头结点1
next=cur->next //先保存当前结点cur的next
cur->next=prev //然后让cur的next指向pre,此时10、20的链就断开了
```
得到：
```text
  prev    cur       next
   ↓          ↓          ↓
  NULL   ←  [10]      [20]  →   [30]  → NULL
            
```

接下来：prev 向前移动，cur 走到下一个节点
```c
prev = cur;
cur = next;
```
变成：
```text
             prev   cur  next
               ↓      ↓   ↓
    NULL ←   [10]     [20]  →   [30]  → NULL
             
```

下一轮：
```c
next = cur->next;//保存30
```
             prev       cur       next
               ↓         ↓          ↓
   NULL ←    [10]      [20]  →    [30] → NULL
