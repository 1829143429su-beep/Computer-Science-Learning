#### 4.删除指定位置的节点
核心语句：
```c
cur->next = cur->next->next;
```
```text
删除下标 pos
        ↓
cur 停在 pos - 1
        ↓
我们先把要删除的节点保存下来：
Node* temp = cur->next;
free(被删除的节点); //否则会造成内存泄漏。
        ↓
cur->next = cur->next->next
```

还有 两个边界情况需要处理
```text
① pos = 0 会出问题
pos = 0;
条件变成：i < -1，循环不会执行。
于是 cur 还是指向头节点

解决：
if (pos == 0)
{
   Node* temp = *pp;       // ① 保存旧头结点地址
   *pp = (*pp)->next;      // ② 让p指向下一个结点
    free(temp);            // ③ 释放旧头结点
    return;
}
//p 和 temp 是两个指针变量，但它们保存的是同一个地址。
//先用一个临时指针temp保存重要的地址，等确认操作完成后，再处理原来的指针

```
```text
② pos 超出范围时还可能出问题
```

#### 8.链表逆序！！！
```c
void reverse_list(Node** pp)
//主函数里p本来指向头结点，逆序后指向原本的终结点
//故需要修改指针p，使用二级指针
```
```text
第一个指针：cur
Node* cur = p;
它负责：当前正在处理的节点。

第二个指针：prev
Node* prev = NULL;
它负责：当前节点的前一个节点。

这就是第三个指针：next
Node* next;
它负责：下一个节点


初始：
  prev       cur       
   ↓          ↓          
  NULL       [10]  →   [20]  →   [30]  → NULL
```

然后第一次执行：保存 20，然后反转 10 的箭头
```c
Node* cur = p; //cur指向头结点1
next=cur->next //先保存当前结点cur的next
cur->next=prev //然后让cur的next指向pre,此时10、20的链就断开了
```
得到：
```text
  prev    cur       next
   ↓          ↓          ↓
  NULL   ←  [10]      [20]  →   [30]  → NULL
            
```

接下来：prev 向前移动，cur 走到下一个节点
```c
prev = cur;
cur = next;
```
变成：
```text
             prev   cur  next
               ↓      ↓   ↓
    NULL ←   [10]     [20]  →   [30]  → NULL
             
```

下一轮：
```c
next = cur->next;//保存30
```
```text
             prev       cur       next
               ↓         ↓          ↓
   NULL ←    [10]      [20]  →    [30] → NULL
```

#### 5.找到第一个值为 target 的节点，在它后面插入一个新节点。

#### 6.删除所有值为 target 的节点
```text
① 头结点删除后，cur 没有更新
你这里：
if (cur->data == target) {
    temp = *pp;
    *pp = cur->next;
}//cur 仍然指向已经被删除的旧头结点。
//而且你没有：free(temp);

② 删除后不能无条件 cur = cur->next，这是这道题最关键的地方。
例如：
cur
 ↓
[10] → [20] → [20] → [30]

假设第一个 20 要删除：
cur
 ↓
[10] → [20] → [30]
         ↑
       原来的第二个20

注意：cur 还是 [10]。
不能马上：cur = cur->next;
否则就会跳到 [20]，需要停留在所要判断结点的前一个位置上，否则下一轮可能漏掉连续节点的处理。

所以这里有一个非常重要的规律：
删除了 cur->next → cur 不动。
没有删除 → cur 才向后移动。

③ 考虑头结点可能连续出现 target：
p
↓
[20] → [20] → [30] → NULL
如果第一个、第二个节点都是 20，我们应该让谁负责不断删除这些头结点？
```
解决：
```text
对于头结点，不应该只判断一次：
if (cur->data == target)

而应该：
只要当前头结点还是 target，就一直删除。

所以这里应该使用一个：
while
```
