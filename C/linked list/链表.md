### 结点的定义
```c
typedef struct Node
{
    int data; //这个节点真正保存的数据
    struct Node* next; //此时结点的typedef还未定义完成，仍需struct
    //next 是一个指针，保存下一个节点的地址。
}Node;
```
```text
┌──────────────┐
│ data │ next  │
│  10  │  ●────┼────→ 下一个节点
└──────────────┘
```

#### 3.插入结点
[10] → [20] → [30] → NULL

假设我们想在 10 和 20 中间插入一个 15：
```c
Node* p;      // 已经指向10
Node* newNode; // 需要申请空间，再指向15
插入节点：先接后面，再接前面。
newNode->next = p->next;  // 先接住后面的节点
p->next = newNode;       // 再让前面的节点接新节点
```
