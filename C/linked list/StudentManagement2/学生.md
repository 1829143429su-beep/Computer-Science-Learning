## 链表版学生管理系统
### 功能：
```
最终实现：
1. 添加学生
2. 显示所有学生
3. 查找学生
4. 修改学生
5. 删除学生
6. 统计学生数量
7. 释放链表
0. 退出
```

### 易错

#### 
```text
数组不能直接这样赋值：
s.name = "Tom";   // ❌

如果你想在函数里给它赋值，要用字符串复制，例如：
strcpy(s.name, "Tom");
```
####
```text
s.name：数组名本身就是地址 ✅
s.age：int 变量，要传地址 ❌
s.score：double 变量，要传地址 ❌
```

#### 作用域
```text
你把：int id;直接写在了 case 3: 后面。
在 C 语言的 switch 中，case 不是一个自动产生独立作用域的代码块。
在某些 C 编译环境/标准下会报错或产生作用域相关问题。

case 3
  ↓
{        ← 创建一个新的作用域
    int id;
    ...
}        ← 作用域结束
```

#### 调用
改变头指针的：Node** → pp
```c
add_student(pp);
delete_student(pp, id);
free_list(pp);
```
不会改变头指针的：Node*  → *pp
```c
show_studens(*pp);
search_student(*pp, id);
change_student(*pp, id);
get_student_count(*pp);
```

#### 2.添加学生
```c
void add_student(Node** pp)
```

它要完成这几件事：
```text
① 让用户输入一个 Student
        ↓
② 创建 Student 变量 s
        ↓
③ 调用 create_node(s)
        ↓
④ 把新节点接到链表末尾

最后考虑两种情况：
链表为空        → *pp = newNode
链表不为空      → 找到最后一个节点 → 接上 newNode
```
