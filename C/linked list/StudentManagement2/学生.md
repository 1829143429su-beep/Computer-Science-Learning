### 实践
#### 1.创建一个节点
我已经有一个 Student 了，你帮我把它包装成一个 Node。
```c
创建完节点后，我们需要拿到这个节点的地址；所以返回类型为Node
Node* create_node(Student s)
{

}
```
要求：
```text
malloc申请一个Node空间
保存学生数据
next初始化为NULL
返回节点地址
```

#### 2.添加学生
```c
void add_student(Node** pp)
```

它要完成这几件事：
```text
① 让用户输入一个 Student
        ↓
② 创建 Student 变量 s
        ↓
③ 调用 create_node(s)
        ↓
④ 把新节点接到链表末尾

最后考虑两种情况：
链表为空        → *pp = newNode
链表不为空      → 找到最后一个节点 → 接上 newNode
```

#### 3.显示所有学生
```c
void show_students(Node* p)
```

```
Student s = cur->data;//这是把当前节点中的 Student 数据复制一份给 s。
所以：：
s.id
s.name
s.age
s.score
可以直接访问。

当然也可以不复制，直接：
cur->data.id
cur->data.name
cur->data.age
cur->data.score
```

#### 4.查找学生

```c
Node* search_student(Node* p, int id)
```
```text
要求：根据学号查找学生，找到就返回对应节点，找不到返回 NULL。
```
